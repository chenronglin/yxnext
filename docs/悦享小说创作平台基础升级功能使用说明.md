# 悦享小说创作平台基础升级功能使用说明

| 项目 | 内容 |
| --- | --- |
| 适用人员 | 作者、编辑 |
| 适用版本 | 基础升级版 |
| 更新日期 | 2026 年 9 月 3 日 |
| 功能范围 | SI 信息扩展、正文第 0 章、批注回复、项目工作日计划 |

本文介绍本次升级功能的日常使用方法。原有 SI 预发、稿件保存与提交、编辑退回与定稿、质检和导出流程保持不变。

## 1. 功能与角色速览

| 功能 | 编辑 | 作者 |
| --- | --- | --- |
| SI 扩展信息 | 新建、修改、查看和回退版本 | 沿用原有“我的 SI”预发接收流程 |
| 正文第 0 章 | 查看内容，按原流程批注、退回和定稿 | 新增或修改第 0 章，撰写作品介绍 |
| 批注回复 | 创建批注并查看作者回复 | 对编辑创建的有效批注进行一级文字回复 |
| 项目计划 | 项目负责编辑可修改未完成阶段 | 查看计划、状态和修改记录，不可修改 |

权限以当前登录账号和项目归属为准。非项目负责编辑不能修改该项目的阶段计划；已完成、已归档或已取消的项目按只读方式展示。

## 2. 编辑使用说明

### 2.1 填写 SI 扩展信息

1. 进入“SI 选题策划库”。
2. 点击“新建 SI”，或打开已有 SI 后进入编辑页面。
3. 在“基础信息”中填写以下内容：
   - **SI 类型**：手工输入，最多 100 个字符；
   - **创作难度**：手工输入，最多 100 个字符；
   - **参考书籍标题**：可选，最多 255 个字符；
   - **参考书籍链接**：可选，填写完整的 `http://` 或 `https://` 链接。
4. 根据实际需要点击“保存草稿”或“保存并预发”。

SI 类型和创作难度不需要管理员提前设置选项，直接输入即可。上述四个字段均为选填项，不影响原有必填项和 SI 标签的使用方式。

#### 查看和回退 SI 版本

每次保存 SI 都会形成一份版本快照，扩展信息会随快照一同保存。

1. 打开 SI 详情页。
2. 点击“查看版本历史”。
3. 在左侧选择版本，在右侧查看该版本的 SI 类型、创作难度和参考书籍信息。
4. 如需恢复旧内容，点击“回退到此版本”并确认。

回退不会删除后续历史，而是生成一条新的回退版本记录。

### 2.2 创建批注并查看作者回复

创建批注沿用原有操作：

1. 进入项目稿件。
2. 选中需要说明的文字。
3. 在浮动工具栏点击“批注”。
4. 输入批注内容并确认。
5. 按原有流程将稿件提交或退回给作者处理。

作者回复后，回复会直接显示在右侧批注栏对应批注的下方，包括回复人、回复时间和内容。若右侧批注栏被隐藏，可点击页面上的“显示批注”重新打开。

批注回复是独立的沟通记录，不会修改正文，也不会生成新的稿件版本。编辑可以查看回复，但不能代替作者发送回复。

### 2.3 修改项目阶段计划

项目负责编辑可以在项目详情页修改本人负责项目的计划。

1. 进入“我的项目”，打开需要调整的项目。
2. 找到“阶段计划”区域，点击“调整计划”。
3. 填写“本次计划调整原因”。修改原因必填，最多 500 个字符。
4. 修改尚未完成阶段的以下任一内容：
   - **计划开始日**；
   - **计划工作日**；
   - **计划结束日**。
5. 点击“保存”。

计算规则如下：

- 修改“计划工作日”后，系统根据开始日重新计算结束日；
- 修改“计划结束日”后，系统根据开始日和结束日重新计算工作日数；
- 同时操作工作日数和结束日时，以最后修改的项目作为本次计算依据；
- 工作日数必须大于 0，结束日不能早于开始日；
- 周一至周五默认为工作日，法定节假日和调休日期以系统维护的工作日日历为准；
- 开始日和结束日按日期区间统计，开始日如果是工作日则计为第 1 个工作日。

保存成功后，页面会显示更新后的计划，并在“最近修改记录”中保留阶段、修改人、日期和修改原因。

以下情况不能修改：

- 当前编辑不是该项目的负责编辑；
- 项目不是进行中状态；
- 对应阶段已经完成；
- 页面数据已被其他人修改。此时系统会提示刷新，请刷新项目后重新调整。

### 2.4 编辑处理第 0 章

第 0 章在编辑端与普通正文章节使用同一套稿件流程。编辑可以进入“作品介绍”，进行阅读、批注、退回、定稿、质检和导出。

第 0 章由作者在正文阶段创建或调整，编辑无需手工改变章节号。

## 3. 作者使用说明

### 3.1 新增第 0 章

第 0 章用于填写整部书籍的介绍说明，便于后续向运营交接内容。

1. 进入“我的项目”，打开当前项目。
2. 确认项目已进入正文阶段，并且仍处于进行中状态。
3. 在“项目文档”的“正文章节”区域点击“新增章节”。
4. 勾选“设为第 0 章（默认标题为‘作品介绍’）”。
5. 系统会自动完成以下操作：
   - 章节号设置为 `0`；
   - 章节号输入框变为不可编辑；
   - 章节标题自动填写为“作品介绍”。
6. 确认标题后，点击“创建章节”。
7. 在正文章节列表中进入“作品介绍”，按普通章节方式撰写和保存内容。

同一个项目只能有一个第 0 章。第 0 章会固定显示在第 1 章及其他正文章节之前，并按该顺序进入质检、清稿和导出结果。

### 3.2 把已有章节修改为第 0 章

1. 在项目详情的正文章节列表中找到目标章节。
2. 点击该章节操作区中的“修改章节号和标题”按钮。
3. 勾选“设为第 0 章（默认标题为‘作品介绍’）”。
4. 确认自动填写的标题，点击“保存章节信息”。

若项目中已经存在第 0 章，系统会拒绝重复设置。需要先确认现有第 0 章是否应保留，再进行调整。

取消“设为第 0 章”后，该章节将恢复为普通章节设置方式，必须填写大于等于 `1` 的整数章节号。普通章节的数字输入框不接受 `0`，需要创建第 0 章时应使用勾选项。

章节结构进入质检阶段后会被锁定，不能再新增、删除或修改第 0 章。未提交的草稿章节可以在项目详情中删除；已经提交过的章节不能从此入口删除。

### 3.3 回复编辑批注

作者可以直接回复编辑在稿件中创建且仍然有效的批注。

1. 进入“我的项目”，打开编辑退回或需要处理的稿件。
2. 在右侧批注栏找到需要回复的批注。若批注栏已隐藏，点击“显示批注”。
3. 在输入框中输入回复内容，输入框提示为“回复批注”。
4. 点击“回复”。

使用限制：

- 回复仅支持纯文字，最多 2000 个字符；
- 当前仅支持一级回复，不能继续对某条回复嵌套回复；
- 只有项目作者可以发送回复；
- 只能回复项目编辑创建且当前仍有效的批注；
- 项目结束、归档或取消后不能新增回复；
- 已发送回复目前不能修改或删除，请发送前确认内容。

回复发送成功后会立即显示，刷新页面后仍然保留。发送回复不会修改稿件内容、不会触发自动保存，也不会生成新的稿件历史版本，因此需要修改正文时仍应在编辑区正常修改并按原流程提交。

原批注失效后不能再新增回复，但已经发送的历史回复仍可查看。

### 3.4 查看项目计划

作者可以在项目详情页查看以下计划信息：

- 各阶段的计划开始日；
- 计划工作日数；
- 计划结束日；
- 实际开始和实际完成日期；
- 当前进度状态；
- 最近修改记录。

作者没有“调整计划”按钮。如计划需要变更，请联系项目负责编辑处理。

## 4. 常见问题

### 4.1 为什么看不到“新增章节”或章节修改按钮？

请依次确认：

- 当前使用的是项目作者账号；
- 项目处于进行中状态；
- 项目已经进入正文阶段；
- 项目尚未进入质检阶段。

### 4.2 为什么不能创建第 0 章？

常见原因是项目中已经存在第 0 章，或当前章节结构已因进入质检阶段而锁定。第 0 章必须通过弹窗中的“设为第 0 章”选项创建，不能在普通章节数字框中直接输入 `0`。

### 4.3 为什么批注下没有回复输入框？

可能原因包括：

- 当前账号不是该项目作者；
- 项目已经结束、归档或取消；
- 原批注已被删除或已经失效；
- 该内容不是项目编辑创建的有效批注。

### 4.4 为什么编辑看不到“调整计划”按钮？

只有当前项目的负责编辑可以调整计划。项目不是进行中状态或阶段已经完成时，也会按只读方式显示。

### 4.5 为什么保存计划后结束日发生变化？

系统按工作日而不是自然日计算。周末、节假日和调休日期都会影响结果；修改工作日数时，结束日会自动重新计算。

### 4.6 为什么参考书籍链接无法保存？

请填写以 `http://` 或 `https://` 开头的完整链接，不要填写本地文件路径、网盘客户端路径或其他协议地址。

## 5. 使用建议

- SI 类型和创作难度采用简短、统一的业务表述，避免同一含义使用多种写法；
- 第 0 章只填写作品整体介绍和运营交接信息，不作为普通故事章节使用；
- 回复批注时明确说明处理结果；需要修改正文的，仍应同步修改稿件内容；
- 调整项目计划时填写具体原因，例如“章节数量增加”或“等待资料确认”，便于后续追溯；
- 重要操作完成后刷新页面，确认数据、状态和修改记录已正确更新。

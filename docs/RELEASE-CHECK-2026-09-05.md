## 依赖审计剩余项

使用官方 npm registry 完成 `npm audit --omit=dev`。最终仍报告 53 个受影响依赖条目：14 high、37 moderate、2 low、0 critical；这些是依赖树条目数，包含同一根因的传递计数，并非 53 个已证实可利用的应用漏洞。审计不是零告警，不应对外称为“无漏洞”。Next.js 本体的公告和 MariaDB 驱动公告已不再命中；Next.js 条目仍因 PostCSS、sharp 的传递关系被列出。

对剩余高风险条目的当前适用性判断如下：

| 依赖或路径 | 本项目当前使用情况与判断 |
| --- | --- |
| sharp / Next 图片优化 | `next.config.mjs` 明确设置 `images.unoptimized: true`，应用未直接调用 sharp。对应恶意图像处理路径未启用；若未来开启图片优化，应先升级相关依赖 |
| PostCSS / Browserslist | 用于处理项目自身的构建源码与配置，没有向请求开放上传 CSS、source map 或 Browserslist 查询的处理接口。剩余告警主要针对不可信构建输入，继续作为工具链升级事项跟踪 |
| Prisma CLI、@prisma/config、deepmerge-ts、mysql2 | 相关告警由 Prisma 配置、开发工具和 CLI 引入；当前在线数据库查询使用已修复的 MariaDB 适配器。不能把 CLI 配置或数据库连接目标开放给不可信输入 |
| hono、fast-uri、ip-address、js-yaml、brace-expansion | 由工具链等传递引入，未发现应用路由直接使用这些库处理请求。保留为依赖维护事项，避免为了清零审计而盲目升级或降级整个 Prisma 主版本 |
| nanoid | docx 调用不带外部长度参数的默认生成器；公告中的负数或零长度自定义生成入口未使用 |

Tiptap 3.26.1 另有 `mergeAttributes` 的中等风险原型属性告警；当前节点 HTML 属性来自固定扩展属性定义，未发现向该函数传入任意用户 HTMLAttributes 对象的路径。本轮保持编辑器依赖同版本，避免临发布时大幅升级整套 Tiptap；该项仍需在后续依赖升级中处理。

`npm run check:i18n` 退出成功，但报告 1912 个疑似中文界面字面量，属于现有扫描器提示和本次中文表格提示的合集；这不等同于英文界面已经完整翻译，也不是本次数据保存与发布的阻断条件。
